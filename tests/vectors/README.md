# Conformance vectors

Generated by traceseal-observe 1.5.0 with fixed test keys (never use them).

- `chain/01..08-*.json`: one chain `vector-chain` covering model (with
  agent context and requested tool calls), oversight (reviewer
  countersigned), tool (causally linked), policy_decision, a
  chain_key_rotation to a second key at seq 5, a tool receipt under the
  new key, incident and erasure receipts. All must verify, and the chain
  must be complete from genesis.
- `chain/checkpoint.txt`: C2SP checkpoint of the chain (for
  traceseal-chain; traceseal-verify does not check checkpoints).
- `relabelled-fingerprint.json`: a valid signature whose
  `operator_fingerprint` was swapped for another key's. Must FAIL.
